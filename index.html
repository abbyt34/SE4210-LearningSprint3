Can response time reveal a secret?

This is a deterministic teaching simulation. It does not measure real execution time, send requests, or attack a system. The “time units” represent how much comparison work an implementation performs.

Comparison trace

Enter a guess and compare it with the toy secret.

Key idea: An early-exit comparison can stop at the first mismatch. If the amount of work depends on how many leading characters match, an observer may infer information from timing. A constant-time design aims to avoid data-dependent early exits and other secret-dependent timing differences.

Learning note: real systems have noise, compiler effects, caches, network delays, and many other factors. Constant-time security requires careful implementation and testing; this simplified model illustrates one source of leakage only.
